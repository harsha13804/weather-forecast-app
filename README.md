🌤 Weather Forecast Application

A modern, responsive weather forecasting web application built using Python and Flask. It provides real-time weather information, city autocomplete suggestions, and a five-day weather forecast through the OpenWeather API.

🚀 Features
Real-time weather information
City search with autocomplete suggestions
Five-day weather forecast
Temperature and weather conditions
Humidity information
Wind speed details
Responsive dark-mode dashboard
Light and dark theme toggle
API error handling
🛠 Technologies Used
Python
Flask
HTML5
CSS3
JavaScript
REST API
JSON
OpenWeather API

⚙️ Installation
Clone the repository:
bash
git clone https://github.com/YOUR_USERNAME/weather-forecast-app.git

Navigate to the project:
bash
cd weather-forecast-app

Install dependencies:
bash
pip install -r requirements.txt

Create a .env file:
env
WEATHER_API_KEY=your_api_key_here

Run the application:
bash
python app.py

Open your browser:
text
http://127.0.0.1:5000/

🔑 API Configuration

Get your API key from OpenWeather.

Never upload your .env file or expose your API key publicly.
